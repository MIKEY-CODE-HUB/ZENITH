# Zenith Shield for Chrome

1. Download and unzip the Chrome extension from **Distraction Shield** in Zenith.
2. Open `chrome://extensions` in Google Chrome 120 or later and turn on **Developer mode**.
3. Click **Load unpacked** and select the extracted folder with `manifest.json`. The extracted Mac download also contains the manifest at its top level. Remove the older Zenith Shield entry before loading the new version. Reload the Zenith tab after installation.
4. Start a focus session with **Distraction Shield** enabled. The room and extension popup show when website protection is active.

Chrome blocks new requests to restricted domains and brings the focus tab forward when you try to open a blocked site. Rules clear when the session ends, you leave the room, the timer expires, or Chrome closes. If you install mid-session, open the extension popup and select **Reconnect current focus room**.

For desktop app blocking on macOS, use the Mac download on Zenith's **Distraction Shield** page and run the one-time setup in **Mac App Setup** in Finder. Chrome starts the helper during protected sessions.
